# Brass: Birmingham（ブラス：バーミンガム）

[English](README.md) · [简体中文](README.zh-CN.md) · **日本語**

ボードゲーム『ブラス：バーミンガム』(Brass: Birmingham) をブラウザで遊べるオンライン対戦版です。

> 本プロジェクトは非公式のファンメイド作品です。[Brass: Birmingham](https://roxley.com/products/brass-birmingham) のデザインは Gavan Brown、Matt Tolman、Martin Wallace、出版は Roxley Games です。ぜひ実物のゲームを購入して原作を応援してください。

**2〜4 人** · **運河時代 + 鉄道時代** · **オンラインルーム**

## 機能

- 建設・ネットワーク・開発・販売・借金・偵察・パスの全アクションと、時代終了時の得点計算および運河時代から鉄道時代への移行
- 石炭・鉄・ビールの調達、市場価格、収入、手番順を自動で処理（調達元を手動で選ぶことも可能）
- オンラインルームで友達と対戦でき、切断しても進行中のゲームに復帰可能
- 実行できないアクションには、その理由となるルールを表示
- 運河時代のみで遊ぶ入門用バリアント（任意）
