# Brass: Birmingham（工业革命：伯明翰）

[English](README.md) · **简体中文** · [日本語](README.ja.md)

桌游《工业革命：伯明翰》(Brass: Birmingham) 的在线多人版本，在浏览器里就能玩。

> 本项目为非官方爱好者作品。[Brass: Birmingham](https://roxley.com/products/brass-birmingham) 由 Gavan Brown、Matt Tolman 和 Martin Wallace 设计，Roxley Games 出版。欢迎购买实体游戏支持原作。

**2–4 人** · **运河时代 + 铁路时代** · **在线房间**

## 功能

- 完整的游戏流程：建造、建设网络、发展、销售、贷款、侦察和跳过，包含时代结算以及运河时代到铁路时代的切换
- 自动获取煤、铁和啤酒，自动处理市场价格、收入和回合顺序；也可以手动选择资源来源
- 与朋友在在线房间对战，掉线后可以重新回到进行中的对局
- 操作不合法时会提示是哪条规则不允许
- 可选的入门版（仅运河时代）
